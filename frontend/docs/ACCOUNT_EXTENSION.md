# 회원 기능 연결 위치 (Phase 4)

현재 `/login`·`/signup`은 입력 UI만 제공한다. API 호출·계정 생성·세션·영구 저장·기능 잠금은 없다. 기본 제작과 ZIP 저장은 계속 비회원에게 제공한다. 새 의존성은 추가하지 않았다.

## 향후 승인 범위에서 연결할 위치

| 확장 | 기존 연결 위치 | 후속 작업 |
| --- | --- | --- |
| 실제 인증 | `src/pages/AccountPage.tsx`의 제출 처리 | 인증 API·실제 응답 기반 세션·서버 검증을 별도 설계한다. 현재 미연결 안내를 성공 처리로 재사용하지 않는다. |
| 무료 회원 추가 샘플 | `src/features/blocks/`의 샘플 정의·홈 샘플 선택 | 추가 샘플 데이터와 제공 기준을 연결한다. 기존 비회원 샘플은 유지한다. |
| 무료 회원 테마 | `src/features/blocks/`의 사이트 CSS·제작 화면 | 테마 정의와 선택 UI를 승인된 범위에서 추가한다. 현재 테마 선택·권한 상태를 미리 만들지 않는다. |
| 구독 회원 고급 기능 | `src/pages/MakerPage.tsx`·`src/features/editor/` | 실제 구독 확인 방식이 정해지면 기능 진입점을 연결한다. 현재 결제·플랜·기능 잠금은 없다. |

입력 정보는 `AccountPage`의 지역 상태에만 둔다. 로그인·회원가입 라우트에 서로 다른 key를 사용해 이동 시 폼을 새로 생성하고, 유효한 제출 후에도 입력을 비운다. localStorage·sessionStorage·쿠키·프로젝트 상태에는 넣지 않는다. 브라우저 자체의 자동완성·비밀번호 관리 기능은 애플리케이션 저장과 별개이며 자동완성을 요청하지 않도록 설정했다.
