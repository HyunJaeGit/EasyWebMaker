구현 근거: [GrapesJS Component API](https://grapesjs.com/docs/api/component.html)의 resizable과 setDragMode. 일반 배치는 기존 요소 순서 드래그를 유지하고, 자유 이동은 사용자가 켠 절대 위치 요소에 적용합니다.

별도 저장 경로는 제거했습니다. 프로젝트 메뉴의 내보내기 모달과 불러오기 모달을 사용합니다. 프로젝트 파일 형식은 v3이며, 페이지 이름을 바꾸면 다음 ZIP에서 종속 HTML·CSS·JS 이름을 함께 변경합니다.
