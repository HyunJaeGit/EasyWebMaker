기존 Phase 3~5 문서는 당시 검증 기록이며, 아래가 이번 변경의 검증 범위입니다.

우클릭/F2 이름 변경은 `.qa/rename-f2-check.cjs`로 Edge 1440·390px 메인 문서와 캔버스 iframe의 F2, 우클릭 변경, 입력 중 단축키 제외, 빈 이름 오류, Esc 취소와 속성 보조 영역 접힘/펼침을 확인했습니다. 이름 입력은 속성에서 제거하고 공통 대화상자로 이동했습니다. 타입·프로덕션 빌드 및 1440·390·320px 페이지/ZIP 회귀 통과.

헤더·툴팁 후속 변경은 `.qa/header-tooltips-check.cjs`로 Edge 1440·390·320px 홈/제작 공통 로그인·준비 중 프리미엄, 로그인 이동, 메뉴 내부 이동 유지/이탈 닫기, 카테고리 제목 도움말의 28px 클릭 영역·클릭 시 카테고리 유지·Esc 닫기를 확인했습니다. 요소 이름 회귀 스크립트도 재실행했습니다. 타입·빌드 통과.

요소 이름 기능은 `.qa/element-names-check.cjs`로 자동 이름·공백 정리·빈 값 거부·중복 경고/허용·복사본 번호·삭제 뒤 번호 유지·이름 변경 undo/redo·이름표·기존 구역 이름과 ZIP 이름 보존/복원을 실제 Edge PC에서 확인했습니다. 파일명/탭 검증도 별도로 재실행했습니다.

설명/구역 이름/밀도 후속 변경: `.qa/compact-guides-check.cjs`로 Edge 1440·390·320px 툴팁 hover·focus·Esc, 이름표 생성과 pointer-events:none, 배율 변경, 표시 해제 후 오버레이 제거, 출력 HTML/CSS/JSON에 편집 오버레이 미포함, 문서 넘침 없음 확인. 캔버스 상단 위치는 900px 높이에서 약 158/183/183px. `.qa/page-tabs-check.cjs`의 페이지 기능 회귀도 통과했습니다. 브라우저 오류 없음, 타입·프로덕션 빌드 통과.

후속 파일명·탭 변경도 프로덕션 빌드에서 확인했습니다. Edge 1440·390·320px에서 한글·대문자·숫자 시작·공백·언더스코어·중복·확장자 입력 차단, about-us 생성, 탭 클릭/방향키/Home 전환, 페이지 최상위/body 하위 구조와 body 선택, contact 이름 변경 후 HTML/CSS/JS 내보내기 및 복원을 통과했습니다. `.qa/page-tabs-check.cjs`에 검증 스크립트를 보관합니다.

검증 스크립트는 무시되는 `.qa/revision-check.cjs`, `.qa/compatibility-check.cjs`에 보관했습니다. 실물 터치로 리사이즈/자유 이동, 다른 브라우저, 실제 GitHub Actions 배포는 수행하지 않았습니다.

구현 근거: [GrapesJS Component API](https://grapesjs.com/docs/api/component.html)의 resizable과 setDragMode. 일반 배치는 기존 요소 순서 드래그를 유지하고, 자유 이동은 사용자가 켠 절대 위치 요소에 적용합니다.

별도 저장 경로는 제거했습니다. 프로젝트 메뉴의 내보내기 모달과 불러오기 모달을 사용합니다. 프로젝트 파일 형식은 v3이며, 페이지 이름을 바꾸면 다음 ZIP에서 종속 HTML·CSS·JS 이름을 함께 변경합니다.
