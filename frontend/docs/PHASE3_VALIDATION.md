## 실패·미실행 검증

잘린 ZIP, 지원하지 않는 버전, 필수 블록 누락, script.js 누락, 이미지 파일 누락, 자산 참조 불일치, 외부 수정 JS, CSS 외부 참조, 이벤트 속성, 중복 블록 ID, 이미지 MIME 불일치, 경로 탈출, 손상 JSON, project.json 없는 외부 사이트, 압축 해제 크기 초과 등 **15종**에서 오류 안내와 기존 이름·내용·undo/redo 보존을 확인했다.

JS 파일과 메타데이터 해시를 함께 변경한 검증 파일도 불러왔지만 해당 JS와 블록의 임의 script 속성은 실행되지 않았다. 재편집 모델은 허용한 JSON 필드로만 재구성하고 ZIP의 출력 HTML·CSS·JS를 실행하거나 역수입하지 않는다.

외부 이미지 요청을 실제로 실패시켜 다운로드가 발생하지 않고 오류가 표시되는 것을 확인했다. 저장의 누락 방지에 대한 확인이며 모든 외부 이미지 호스트의 CORS를 보장하지 않는다.

왕복 검증 중 GrapesJS의 여백 세부 속성 변환을 발견해 CSSOM으로 표준 축약값을 저장하도록 보완했다. 미리보기의 격리된 출처로 인한 글꼴 차이는 스크립트를 허용하지 않는 동일 출처 sandbox로 수정하고 독립 출력과 다시 비교했다.

## 직접 재확인 방법

```bash
cd frontend
npm ci
npm run build
npm run preview
```

터미널의 Local 주소에서 샘플을 편집하고 ZIP을 다운로드한다. 압축을 풀어 index.html을 열어 이미지와 링크를 확인한다. 새 빈 프로젝트에서 ZIP을 불러온 뒤 같은 내용·스타일·순서·이미지를 확인하고 다시 편집한다. 검증용 ZIP 복사본에서 project.json이나 이미지를 제거한 후 불러오기 오류와 기존 작업 보존을 확인한다.

## 미검증·남은 범위

- 실물 모바일 기기, Safari·Firefox, 모든 외부 이미지 호스트, JPG·WebP·GIF 각각의 왕복은 별도 검증하지 않았다. 실제 왕복 이미지 검증은 PNG·기본 SVG다.
- 자동 새로고침 복원, 온라인 저장, 백엔드, React 출력은 구현하지 않는다.
- GitHub 배포 설정 생성은 Phase 5. 저장소 연결·push·실제 배포는 하지 않았다.
- 기존 엔진 청크 크기 안내는 남아 있으며 ZIP 모듈은 필요한 화면에 지연 로딩된다.
