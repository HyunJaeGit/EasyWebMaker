# Phase 4 회원 UI 검증

2026-10-11 · 실제 Microsoft Edge · 프로덕션 미리보기.

- 1440·768·390·320px에서 로그인·회원가입 입력과 상호 이동, 필수 입력·잘못된 이메일·비밀번호 불일치 오류를 확인했다.
- 첫 오류 입력으로 초점 이동, Enter 제출, 유효한 제출 후 미연결 안내와 입력 초기화를 확인했다. 계정·로그인 상태는 생성하지 않았다.
- 화면 이동 후 이메일·비밀번호가 남지 않음을 확인했다. 폼 테스트 중 fetch/XHR/POST 요청·Storage.setItem 호출·쿠키가 없었다.
- 작은 화면 가로 초과·브라우저 런타임 오류 없음. PC·320px 화면 캡처를 확인했다.
- 320px 터치 이벤트로 로그인·회원가입 이동과 제출을 확인했다.
- 회원 화면 왕복 후 기존 제작 내용 유지, 저장 화면 실제 ZIP 다운로드 후 project.json의 편집 내용 유지, 편집 화면 복귀를 확인했다.
- TypeScript·프로덕션 빌드 통과. 기존 GrapesJS 청크 크기 안내는 유지한다. 의존성 추가 없음.

실물 모바일·Safari·Firefox와 실제 인증은 검증하지 않았다. 실제 인증·계정 생성·세션·결제·기능 잠금은 구현 범위에서 제외한다.

Git Bash에서 `cd frontend`, `npm run build`, `npm run preview` 후 `/#/login`·`/#/signup`을 방문해 입력 오류와 미연결 안내를 재확인할 수 있다.
