# EasyWebMaker · 이지웹메이커

마우스로 블록을 배치하고 수정해, 코딩 없이 웹사이트를 쉽게 만드는 GUI 기반 웹사이트 제작 도구입니다.

학교·공공기관 스타일의 샘플을 활용하거나 빈 화면에서 시작할 수 있습니다. 완성한 웹사이트는 파일로 내려받고, 저장한 프로젝트를 다시 불러와 이어서 편집할 수 있습니다.

🔗 [이지웹메이커 사용하기](https://hyunjaegit.github.io/EasyWebMaker/)

## 프로젝트 소개

웹사이트 제작에 필요한 작업을 화면에서 직접 수행할 수 있도록 만든 블록 기반 노코드 웹사이트 빌더입니다.

사용자는 텍스트·이미지·버튼 등의 블록으로 페이지를 구성하고, 속성 패널에서 내용과 스타일을 수정할 수 있습니다.

**제작 → 미리보기 → ZIP 내보내기 → 다시 불러와 편집하기**까지 하나의 흐름으로 제공합니다.

현재는 프런트엔드 MVP이며, 기본 제작과 파일 저장은 로그인 없이 이용할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 샘플 선택 | 학교·공공기관 스타일의 샘플 또는 빈 프로젝트로 시작 |
| 블록 추가 | 헤더, 히어로, 텍스트, 이미지, 카드, 버튼, 컨테이너, 푸터, 갤러리, 안내·CTA, 연락처 |
| 시각적 편집 | 내용, 색상, 글꼴, 크기, 정렬, 여백, 테두리, 배경, 배치 수정 |
| 요소 관리 | 구조 트리, 이름 변경, 이동, 복제, 삭제, 잘라내기·붙여넣기 |
| 실행 기록 | 실행 취소·다시 실행 |
| 다중 페이지 | 최대 20개 페이지 생성, 이름 변경, 탭 전환 |
| 미리보기 | PC·태블릿·모바일 화면 크기별 확인 |
| 작업 화면 조절 | 캔버스 확대·축소, 구역 경계 표시, PC 패널 크기 조절 |
| ZIP 내보내기 | HTML·CSS·JS, 이미지·글꼴, 재편집용 데이터 저장 |
| 프로젝트 복원 | 저장한 ZIP을 검증하고 불러와 이어서 편집 |
| 배포 파일 제공 | 일반 정적 호스팅 또는 GitHub Pages용 파일 생성 |

## 사용 방법

1. 빈 프로젝트 또는 샘플을 선택합니다.
2. 블록을 클릭하거나 PC에서 드래그해 추가합니다.
3. 요소를 선택하고 내용과 스타일을 수정합니다.
4. 필요한 페이지를 추가하고 화면 크기별 미리보기를 확인합니다.
5. 프로젝트 메뉴에서 ZIP으로 내보냅니다.
6. 다시 작업할 때 저장한 ZIP을 불러옵니다.

> 자동 영구 저장은 지원하지 않습니다. 새로고침하거나 탭을 닫기 전에 ZIP으로 저장해 주세요.

## 내보내기

완성한 사이트는 편집 엔진 없이 실행되는 정적 웹사이트 파일로 출력됩니다.

페이지 이름이 `home`, `about`인 경우 다음과 같이 구성됩니다.

    my-site.zip
    ├── home.html
    ├── home.css
    ├── home.js
    ├── about.html
    ├── about.css
    ├── about.js
    ├── assets/
    └── project.json

- 페이지별 HTML·CSS·JS를 생성합니다.
- 이미지와 Pretendard 글꼴·라이선스를 함께 포함합니다.
- 자산은 상대 경로로 연결합니다.
- 편집 도구의 표시 요소와 편집용 속성은 출력에서 제외합니다.
- `project.json`에 재편집을 위한 페이지·블록·스타일·자산 정보를 저장합니다.
- 현재 출력 JS에는 실행 기능 없이 안내 주석만 포함됩니다.

GitHub Pages 방식으로 내보내면 배포 워크플로와 안내 문서도 포함됩니다. 실제 저장소 설정과 업로드는 사용자가 진행합니다.

## 기술 스택

| 기술 | 용도 |
| --- | --- |
| React | 화면 구성과 상태 관리 |
| TypeScript | 타입 검사 |
| Vite | 개발 서버와 빌드 |
| React Router | 해시 기반 라우팅 |
| GrapesJS | 시각적 웹페이지 편집 엔진 |
| fflate | ZIP 생성과 압축 해제 |
| Pretendard | 한글 글꼴 |
| GitHub Actions · Pages | 배포 워크플로 |

정확한 버전은 `frontend/package.json`과 lock 파일에서 관리합니다.

## 주요 구현

### 편집 기능 구성

GrapesJS를 기반으로 블록 선택, 구조 트리, 속성 편집, 페이지 관리 기능을 구성했습니다.

### 독립 실행 파일 생성

편집한 페이지를 HTML·CSS·JS로 출력하고, 이미지와 글꼴을 함께 패키징합니다.

### 프로젝트 저장과 복원

재편집용 프로젝트 규격을 정의하고 ZIP 저장·불러오기 흐름을 구현했습니다. 현재 저장 규격은 v3이며 기존 v1·v2 ZIP도 검증 후 복원합니다.

### 불러오기 검증

ZIP 경로·크기·CRC, 필수 파일, 프로젝트 구조, 자산 참조·형식, SHA-256 해시를 검사합니다.

검증에 실패하면 기존 작업과 실행 기록을 유지합니다. 가져온 JavaScript는 실행하지 않으며, 임의의 외부 HTML을 편집 프로젝트로 불러오는 기능은 지원하지 않습니다.

## 로컬 실행

Git Bash에서 실행합니다.

    git clone https://github.com/HyunJaeGit/EasyWebMaker.git
    cd EasyWebMaker
    npm --prefix frontend ci
    npm run dev

터미널에 표시되는 Local 주소로 접속합니다.

기본 주소: `http://localhost:5173`

기존 검증 환경은 Node.js 24.16.0, npm 11.13.0이며 Node 버전은 `.nvmrc`에 지정되어 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run typecheck` | TypeScript 검사 |
| `npm run build` | 타입 검사와 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |

빌드 결과는 `frontend/dist/`에 생성됩니다.

## 현재 범위와 제한

- 로그인·회원가입은 입력 UI와 유효성 검사만 구현되어 있습니다.
- 실제 인증·온라인 저장·서버·DB·API·결제는 연결되지 않았습니다.
- 페이지 삭제·복제·페이지 간 링크 선택은 후속 개발 범위입니다.
- 샘플의 게시판·검색·접수는 화면 구성 예시입니다.
- 이미지 업로드는 PNG·JPG·WebP·GIF, 최대 5 MB를 지원합니다.
- 외부 이미지는 다운로드 가능한 CORS 설정이 필요합니다.
- ZIP은 최대 25 MB, 압축 해제 총량은 최대 32 MB입니다.
- 실물 모바일 및 Safari·Firefox 추가 검증은 남아 있습니다.
